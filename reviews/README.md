# Review reports

Rounds 1–4 (code) and 1–3 (design) were written for the earlier version of this app,
before it moved to the current Flows template (Aura 0.3.5 at the time, Aura 1.x now).
The source code was the same, but the package audits and the Aura notes in those
rounds describe the old setup. Code review round 8 and design review round 7 are the latest and the ones that
count for certification. Round 8 re-checks the 1.0.0 production release (Zod validation at the trust
boundaries, the navigation refactor and the bundle split); design round 7 covers the UI (with a walkthrough on real CDF data); it has not
changed visually since (rounds 5 and 4 were the first reviews on the current template).
